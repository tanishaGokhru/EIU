# Economic Indicators Forecasting (EIU)

## Problem
Forecast key macroeconomic indicators (e.g., CPI, inflation, GDP trends).

## Approach
- Data cleaning (interpolation, handling missing values)
- Time series techniques (ARIMA / regression / Bayesian models)

## Results
- Forecast plots
- Key insights (e.g., inflation trend increasing)

## Tools
Python, Pandas, NumPy, Matplotlib
